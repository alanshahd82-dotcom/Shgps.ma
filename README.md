# 🛰️ Shgps.ma — Demo تفاعلي

نموذج تفاعلي احترافي لمنصة تتبع GPS موجهة لسوق مغربي/عربي.

## 🚀 تشغيل المشروع

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`

## 📱 محتوى الديمو

### تطبيق العميل (Mobile)
- Splash Screen متحرك بلوغو Shgps.ma
- شاشة تسجيل دخول
- خريطة مباشرة مع حركة الأجهزة (Live Tracking)
- Carousel إعلاني قابل للتمرير تلقائياً
- قائمة الأجهزة مع حالاتها
- تفاصيل كل جهاز: السرعة، البطارية، سجل الرحلات
- قطع/تشغيل المحرك عن بعد مع تأكيد
- رسم Geofence على الخريطة
- التنبيهات مع عداد للمقروءة
- إعدادات + تبديل اللغة (عربي/فرنسي)

### لوحة Admin (Web Dashboard)
- تسجيل دخول خاص بالأدمن
- Dashboard مع إحصائيات + رسوم بيانية (Recharts)
- إدارة العملاء (إضافة/حذف)
- إدارة الأجهزة لكل عميل
- جدول الأجهزة الشامل مع فلترة
- خريطة تعرض كل الأجهزة
- مركز التنبيهات العامة

## 🔐 تسجيل الدخول

أنشئ حسابات العملاء والمدير من لوحة الإعداد أو مباشرة عبر قاعدة البيانات.
لا تُخزّن بيانات دخول افتراضية في الكود أو في الريبو العام.

## 🛠️ التقنيات

- **React 18** + Vite
- **Tailwind CSS** — نظام تصميم مخصص
- **Leaflet / react-leaflet** — خرائط OpenStreetMap
- **Recharts** — رسوم بيانية للـ Admin
- **Framer Motion** — انتقالات ناعمة
- **React Router v6** — التنقل بين الشاشات
