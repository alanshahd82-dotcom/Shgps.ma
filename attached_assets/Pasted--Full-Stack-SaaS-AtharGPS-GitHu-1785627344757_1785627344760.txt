البنية التقنية:
- Frontend: React 18 + Vite + Tailwind CSS + React Router v6 (BrowserRouter)
- Backend: Node.js + Express + PostgreSQL
- DevOps: Docker + Nginx (على الخادم الحي)
- خدمة خارجية: Traccar API للتتبع

القواعد الثابتة:
- BrowserRouter مستخدم في App.jsx (ممنوع HashRouter)
- المسار الجامع <Route path="*" /> في آخر سطر دائماً
- جميع النصوص تدعم العربية والفرنسية (i18n)
- ممنوع البيانات الوهمية (Mock Data)
- أي Migration جديدة يجب أن تكون ذاتية الشفاء (IF NOT EXISTS)

المسارات الحالية (لا تغيرها):
- /client/login - تسجيل دخول العميل
- /client/devices - قائمة الأجهزة
- /client/device/:id - تفاصيل الجهاز
- /client/alerts - التنبيهات
- /client/settings - الإعدادات
- /client/reports - التقارير
- /client/maintenance - الصيانة
- /admin/login - تسجيل دخول الأدمن
- /admin/dashboard - لوحة التحكم
- /admin/clients - إدارة العملاء
- /admin/devices - إدارة الأجهزة
- /share/:token - مشاركة الموقع (عام)
- /* - إعادة توجيه للصفحة الرئيسية
