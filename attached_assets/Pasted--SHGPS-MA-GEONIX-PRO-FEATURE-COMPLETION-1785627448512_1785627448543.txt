───────────────────────────────────────────────────

خوارزمية النقاط (من 100):
  نقطة البداية: 100
  - تجاوز سرعة مرة واحدة: -10 نقاط (من Traccar events type=speedLimit)
  - كبح مفاجئ: -5 نقاط (acceleration < -8 m/s²)
  - قيادة أكثر من 4 ساعات متواصلة: -5 نقاط
  - قيادة ليلية (12AM-5AM): -3 نقاط
  الحد الأدنى: 0

  - النقاط من 100 + نجوم (⭐)

• مخطط خطي للنقاط خلال آخر 30 يوم
• Leaderboard: ترتيب السائقين من الأفضل للأسوأ
• تفاصيل الأحداث لكل سائق (تجاوزات، توقفات)

🌐 Traccar API Reference (للرجوع إليها):
══════════════════════════════════════════════════════

Base URL: http://traccar:8082  (داخل Docker network)

GET  /api/session         ← تسجيل دخول Traccar
GET  /api/devices         ← جميع الأجهزة
GET  /api/positions       ← آخر مواقع جميع الأجهزة
POST /api/devices         ← إضافة جهاز جديد {name, uniqueId}
GET  /api/reports/route?deviceId=X&from=Y&to=Z   ← تاريخ المسار
GET  /api/reports/events?deviceId=X&from=Y&to=Z  ← الأحداث
GET  /api/reports/summary?deviceId=X&from=Y&to=Z ← ملخص (مسافة، ساعات)
GET  /api/geofences       ← المناطق الجغرافية
POST /api/geofences       ← إضافة منطقة جديدة
WSS  /api/socket          ← WebSocket للتحديث الفوري

جميع هذه الـ endpoints موجودة في backend/src/services/traccar.js

□ 1. جميع الـ 13 مهمة مطبقة بالكامل
□ 2. npm run build ينجح بدون أخطاء
□ 3. لا يوجد console.error في المتصفح عند تشغيل التطبيق
□ 4. كل النصوص الجديدة موجودة في translations.js (ar + fr)
□ 5. كل الصفحات تعمل بشكل صحيح على شاشة 375px عرض
□ 6. Dark Mode يعمل في جميع الصفحات بدون أخطاء بصرية
□ 7. WebSocket يتحدث في الوقت الفعلي (يمكن اختباره بمحاكاة حركة جهاز)
□ 8. لا توجد بيانات وهمية (كل شيء من Traccar API)
□ 9. جميع الـ migrations اشتغلت بنجاح على PostgreSQL
□ 10. التطبيق يعمل على Capacitor (npx cap sync لا يعطي أخطاء)
